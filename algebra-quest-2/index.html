How to Play

Three quick ideas and you're ready. Try the example as you go!

1 · x is just a mystery number

In x + 7 = 15, x is hiding a number. Your job: figure out which number makes both sides equal.

x + 7 = 15  →  take 7 away from both sides  →  x = 8

2 · Do the same thing to both sides

An equation is like a balanced scale. Whatever you do to one side, do to the other — add, subtract, multiply, or divide — until x is on its own.

2x + 3 = 11 → minus 3 → 2x = 8 → divide by 2 → x = 4

3 · Patterns: find the rule

Look at how each number changes. In 4, 7, 10, 13, … each step adds 3, so next is 16. Check the gaps between numbers first!

Practice rounds

Pick Practice Round on the start screen (or tap the green Practice button) to warm up first. Same grade band and quest type, but no stars and no score is kept. If you miss a question, that answer locks and you try another one right away — use the hint, think it through, and keep going until you find it. Perfect before a scored run.

📜 Rules

  • One quest = 10 questions. Pick a grade band and a quest type before you start.
  • Stars: 4–6 correct = 1 star · 7–8 correct = 2 stars · 9–10 correct = 3 stars. Stars add up and are saved on this device only.
  • Practice rounds earn no stars and keep no score — they're just for learning. Pick “Practice Round” under Round Type, or use the green Start Practice button. In practice, a wrong tap only locks that one answer — you try again on the same question until you get it, then move on.
  • Hints are always free. Using one never takes away a star.
  • One tap per question. After you answer, read the steps, then tap Next.
  • No timer, no lives, no losing. Finish a quest whenever you're ready, or end it early — stars only count for finished quests.
  • Fair play: try it yourself first, then check the hint. That's how the learning sticks!
  • Privacy: no accounts, no names, no chat, no ads, and nothing leaves this device. Stars live in this browser's local storage.
