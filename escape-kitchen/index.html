How to play — 30-second tutorial

No walkthrough is forced on you — this page is here whenever you want it.

1
Search the room

Tap the fridge, drawer, oven, cookbook, cookie jar, clock, doormat or door.

2
Find 3 digits

The fridge magnets, cookbook page and clock each hide one code digit.

3
Find the key

A little brass key is hiding in one searchable spot. Check the cookie jar…

4
Unlock the door

Tap the door, dial in the 3-digit code, and the lock clicks open.

5
Use a hint

Stuck? A hint lights up a useful spot. Easy has 3, Normal has 2, Hard has none.

6
Escape!

With the code cracked and the key in hand, tap the door and walk out.

Picking a difficulty

Easy gives 3 hints and sparkles on spots that still hide clues. Normal gives 2 hints. Hard gives no hints, no sparkles — and one of the notes in the room is a fib.

Rules

The escape

  • You are locked in a cosy kitchen. Everything you need is in this one room.
  • To escape you need both: the 3-digit door code and the little brass key.
  • The clock starts when you press Start (or search your first spot).

The code — 3 digits, any order

  • Fridge magnets hide the 1st digit: 4.
  • The cookbook falls open to page 47 — the 2nd digit is 7.
  • The clock stopped at 2 o'clock — the 3rd digit is 2.
  • Each clue you find joins your inventory with its position, so the code is always 472 no matter which order you find them in.
  • Tap the door to open the code lock and dial the digits in with the up / down buttons.

The key

  • The little brass key is hidden in the cookie jar. Finding it unlocks the door's deadbolt.
  • Other spots are just cosy kitchen life: the oven is warm, the doormat hides crumbs, and the drawer is stuck — something rattles inside.

Hints

  • Easy: 3 hints, and spots that still hide clues sparkle.
  • Normal: 2 hints, no sparkles.
  • Hard: 0 hints, no sparkles, and one scribbled note in the drawer is a red herring — it fibs about the code.
  • A hint lights up the next useful spot. Each hint used lowers your hint bonus.

Score

  • Score = time bonus + hints-left bonus: up to 2000 points for a fast escape (minus 10 per second), plus 150 per hint left unused.
  • Your best escape time and best score are saved on this device.

Practice round

  • Tap Practice round to explore the kitchen with no pressure.
  • Practice never saves anything — no best time, no score. Tap the button again to return to a timed escape.
