# Holo's Arcade — beta site export

Static export of the games-hub artifact (v57) + all 172 games it links to,
built 2026-11-21 for GitHub Pages hosting at beta.holosarcade.ca.

Structure: hub lives in games-hub/ so its ../<game>/ links and each game's
../games-hub/ back-links resolve exactly as they do on muse.ai.
Root index.html redirects to games-hub/.

To refresh: re-run the export from ~/workspace/ts-spaces/<slug>/index.html
(+ assets/) — do not hand-edit files here.
