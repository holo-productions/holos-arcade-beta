How to play

Pick a block from the tray and tap a spot on the grid to place it. Fill every cell in a row or column to clear it and score. When no tray block fits anywhere, the game ends.

Easy uses smaller blocks, Hard adds bigger awkward shapes.

Rules

  • Place all 3 tray blocks to get a fresh tray.
  • Each cleared line scores points; clearing two lines at once scores extra.
  • Game over when no remaining block fits.
  • Practice mode never saves to your best.
