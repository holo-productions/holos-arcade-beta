How to play

Focus Flow has two gentle noticing games. There is no rush — take as long as you like.

1
Spot changes

Two scenes look almost the same.

2
Tap the change

Tap where colour, shape, or something missing changed.

3
Find them all

Found spots get a ring; find all to finish.

4
Spot the odd one

In a grid of matching shapes, one is different.

5
Tap the odd one

Tap the different shape; each correct tap starts fresh.

6
Practice mode

No score pressure, hints on, never a timer.

7
Need a hint?

Hint gently highlights one answer.

8
Optional timer

Adds a soft countdown; leave off for calm.

Rules

  • Find the Difference: tap each changed spot once. Tapping a spot that is the same does nothing — no penalties, ever.
  • Odd One Out: tap the single different shape. A wrong tap just marks that cell softly so you can keep looking.
  • Difficulty changes how many differences or grid cells you get, and how subtle they are. Your choice is saved on this device.
  • Practice mode has no scoring, hints always available, and no timer.
  • Timer (optional): when on, each round has a gentle countdown. If time runs out, the round simply ends and you can start a new one — nothing is lost.
  • Bests (rounds completed and best streaks) are saved only in this browser on this device.
  • This game is for relaxation and fun. Not medical advice.
